# Runtime modules

Each directory here is a runtime module: point `DECK_MODULES_DIR` at this directory and set
`DECK_MODULES_ENABLED=true` to load them. See
[Run a runtime module](../../docs/guides/runtime-modules.md).

| Module | What it adds |
| --- | --- |
| [`maintenance`](maintenance) | Planned maintenance windows: a page, a header pill, a provider, a route and a config section with a rule. |
